# 🩸 Blood Group Finder

A deep learning-powered web application that predicts blood group types (A, B, AB, O) from microscopic blood sample images. This project is built using TensorFlow and Streamlit.

---

## 🚀 Features

- Upload a blood sample image (JPG, PNG)
- Predict blood group: **A**, **B**, **AB**, or **O**
- View confidence score of prediction
- Simple and clean UI using **Streamlit**
- Uses trained CNN model (`blood_group_model.h5`)

---

## 🖥️ Tech Stack

- Python 3.x
- TensorFlow / Keras
- NumPy
- Pillow (PIL)
- Streamlit
